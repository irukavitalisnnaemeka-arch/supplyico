# Supplyico

AI-powered sourcing agent for product businesses.

**We help brands source from international suppliers, benchmark pricing, and manage procurement — powered by AI.**

## How it works

1. **Free Audit** — We benchmark up to 5 of your products against our proprietary pricing database
2. **AI Sourcing** — Our agent finds verified suppliers, negotiates quotes, and manages quality control
3. **You Save** — We charge 25% of verified savings. No savings = no fee.

## Stack

- **Frontend:** Next.js + React
- **Backend:** Python + FastAPI
- **AI:** Claude API + LangChain
- **Database:** PostgreSQL + vector search
- **Hosting:** Vercel + Railway
